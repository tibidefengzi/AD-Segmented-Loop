## 上版新增（0.4.45）：AD-最终保存

连接方式：分段预览的媒体输出 → 放大/插帧等处理工作流 → AD-最终保存的处理后媒体。

1. 在原分段预览中单击一份成果，或Ctrl追加/取消多选，沿用原编号；不增加待加工数量面板。Ctrl选择顺序沿用原合并选择的点击顺序。
2. 点击最终保存节点的“加工所选”，逐份读取选中的已保存文件、执行处理中间分支、保存后再处理下一份。该按钮的提交副本截断原生成祖先，不重跑H3生成，不修改工作画布或循环进度。
3. 视频放大/插帧节点若接IMAGE，使用ComfyUI的视频拆分节点取得帧、音轨和帧率，处理后通过视频合成节点接回最终保存。插帧后的合成帧率应采用目标帧率。直接输入VIDEO时按其实际尺寸、帧率、帧数和声音保存。
4. “帧序列帧率”只用于直接输入的视频帧序列；0沿用已选原视频帧率，做过插帧请明确填写目标值或接视频合成节点。单个IMAGE及图片批次按图片保存。
5. 最终节点按图片/音频/视频分类，保留来源编号。可停止、继续剩余；成功项保留，失败项不跳过。继续剩余采用当前修好的处理中间分支及原文件清单。重开工作流后手动继续，不自动排队。
6. 最终节点“合并片段”：选中时按选择顺序合并；未选时合并当前分类全部未合并成果。支持视频/音频；尺寸、帧率、音轨或编码不一致时，先询问是否采用首条规格统一。该合并路径不套用H3规则，原预览合并保持独立。
7. 保存目录留空时存入ComfyUI/output/AD-Segmented-Loop-final下的分类目录；自定义目录也按图片/音频/视频分类。文件名含来源编号和唯一后缀，保留以前版本；缩略图×只移除预览记录，磁盘文件保留。

新节点不施加24FPS、尺寸对齐倍数或17k+5帧数限制。中间处理节点本身的输入格式与要求仍按各节点设置。

生效：保存工作流、等待当前任务结束后安全重启ComfyUI，再Ctrl+F5；在AD-Segmented-Loop分类中添加“AD-最终保存”。原工作流不自动插入节点或改线。

## 上版新增（0.4.43）

### 1. 轮次编号改为“逻辑轮次”（修复 R3/R4 乱跳）

之前用 `execution_round.id`（每次排队/运行此段/抽卡都会换）当轮号，导致第一轮之后号码乱涨。
现在后端在会话里维护 `round_no`：只有**真正开新一轮**（一轮跑完后再开始 / 清空重置 / 批处理完成）
才 +1；续跑、运行此段、本段抽卡、跳段都不涨。抽卡的 trial 子会话继承父轮号。

- 第二轮普通结果：`R2-05`；第二轮第 1 段抽卡：`R2-01-1`；
- 第二轮开始后，第一轮卡片自动折叠为历史轮，只显示当前轮；
- 点历史轮卡片再点「分段循环 / 本段抽卡」会提示“会作用于当前轮的第 N 段”。

### 2. 时间线缩放卡顿优化

- 滚轮缩放改为 `requestAnimationFrame` 合并：连续滚动每帧最多重绘一次；
- 标尺步长强制每格 ≥42px（放大时不再无限加密刻度），并限制单次绘制上限；
- 缩放锚点改用同一帧的 pxs 计算，鼠标下的时间点不漂。

### 3. 段号漂移修复

图片的「第 N 段参考」在段线增删/移动后，会按**时间重叠**自动迁移到新段号；
如果原段被切分/删除导致无法对应，改为「全局参考」并给出提示。

**生效**：后端改动需重启 ComfyUI；前端改动需 `Ctrl+F5`。

## 本版修复（0.4.42）：系统选择框在 125%/150% 缩放下发糊

素材目录 / 生成目录 / 下载 / 选择目录 / 另存为 的弹框运行在独立子进程里，而
`python_embeded` 默认是 DPI unaware，系统按 96 DPI 渲染后位图拉伸到 125% → 文字图标发糊。
现在弹框进程启动时开启 `PER_MONITOR_AWARE_V2`（带 shcore / SetProcessDPIAware 兜底），
按真实 DPI 渲染。只影响弹框子进程，不碰 ComfyUI 主进程；**需重启 ComfyUI 生效**。

## 本版新增（0.4.41）：轮次编号 + 按点击顺序合并

- **编号改为「轮次-段号」**：`R2-05` = 第 2 轮第 5 段；抽卡 `R2-05-1`、`R2-05-2`。
  旧记录没有轮次信息，按历史轮处理（可展开查看）。

  不点选、直接点「A合并/B合并」时仍按段号顺序整轮合并。

## 上一版新增（0.4.40）：抽卡只换种子，不再重跑上游

「本段抽卡」过去每次都要从「分段生成」把整条链路重算，因为当前段节点的缓存钩子固定返回
`IS_CHANGED = nan`（强制每轮重算）。0.4.40 起改为**稳定缓存键**：段号、素材清单、提示词、分辨率
不变就命中缓存，抽卡只重跑种子相关的采样与解码——与原生 ComfyUI 改种子的行为一致。

**装上即生效，没有开关、没有环境变量、不需要任何配置。**

- **段号怎么进缓存键**：后端在两条排队路径上都会把「段索引」写进当前段节点输入
  （后端排队在 `engine.enqueue`；浏览器直连排队/抽卡在 `rounds.prepare`）。
- **何时失效**：换段、改素材/段线、改提示词、改分辨率、改参考图用途 → 自动重算。
- **何时命中**：同一段只换种子（本段抽卡）→ 上游条件、遮罩、参考编码全部复用。
- **回滚**：没有开关，整包换回旧版本即可；无数据迁移、无文件格式变化。
- **回归测试**：`python -m unittest discover -s tests -p "test_segment_cache_identity.py" -v`

## 安装

   环境要求：本版在 ComfyUI 0.43.0 实测通过，建议使用该版本；更早版本尚未完成兼容验证，暂不声明最低支持版本。

## 轨道与切分
轨道小眼睛：关闭后片段变暗，不参与时间线预览、试听及分段输出；再次开启恢复，分段清单排除隐藏轨道，编辑布局保留。编辑、检测、应用切分、应用分段与运行此段只作用于所选可见音视频片段（Ctrl 可多选），未选择时提示先选择。

参考图口按图片加载顺序固定编号；禁止输出保留原编号但输出为空，指定第N段的图片在第N段从自己的参考图口输出。

长时间运行优化：静态视频缩略图与延迟加载；未变化进度采用条件响应并跳过重复写盘；任务边界轻量回收插件解码缓存。保留抽卡历史、源素材、结果与模型，不增加手动清理或卸载模型按钮。

预览分类区的视频卡片使用后端首帧静态缩略图，并按卡片增量更新：结果很多时不再为每张卡片创建视频解码器、不再整表重建，长时间分段循环的预览刷新更轻。存储占用统计降为 60 秒兜底轮询，切回页面或点击占用栏仍立即刷新。

分段循环切到其它工作流标签或界面后仍继续运行：同一画布内每段按当前生成设置运行，本轮素材与下一轮素材编辑隔离；切到别的工作流时使用启动时提交副本继续，不再依赖当前激活画布；旧图界面刷新失败不会中断生成。
生成即通过：正常生成、本段抽卡、改参数后的新生成都自动作为已通过/当前选用，不再需要「同意批准」；点「开始」生成当前段后自动前进，可一段一段生成，点「分段循环」连续生成。预览区拆为「分段生成A」「分段生成B」「合并生成」：A/B 分别显示媒体A/媒体B输入端口逐段内容，合并生成显示点击合并后的结果。「合并片段」点击后弹出「A合并」「B合并」两个选项，点哪个执行哪个；Ctrl 点选时只合并选中片段，不点选则合并该端全部段的最新结果，结果带 A/B 来源标签；A、B 混选会提示请分别合并。分段循环支持报错修复后从报错段继续；选中本轮任意分段预览，再点分段循环，即从该段下一段继续，不要求先清空。重启后或清空重置后同样可用，前段按各自最后结果恢复，后段重跑并保留旧版本；继续使用本轮素材，不串入下一轮草稿。选择本轮末段只显示完成，不重新排队。单击卡片只预览与选择，不自动运行。任务结束时自动回收过期参考帧临时物与已完成抽卡试运行的进度/轮次快照；清理缓存也会回收被新一轮取代的旧轮快照和过期临时文件，不删除素材、结果、成片或当前轮。整轮设置无法准备（例如素材被移动或改写）时，排队会进入已注册的「本轮排队保护」节点并显示真实原因，不再只报“节点不存在”。

全屏预览无边框、黑底等比放大，按钮可再次点击退出；图片/视频的普通与全屏A/B对比均居中完整显示。

选中片段后播放从所选起点开始，多选取最早起点；同一选择停止后继续当前白线。信息栏显示所选第N段，移除源范围与本段范围文案，内部裁剪/计帧数据保留。

工作流切换恢复使用最新编辑器存档，按节点所属图恢复动态参考口与连线，避免同ID工作流或迟到回调相互影响。

## 本轮执行与编辑

素材按轮隔离：本轮使用启动时的素材清单、取段范围与参考素材绑定。运行中替换或编辑的新素材属于下一轮，不影响当前轮；停止续接仍使用本轮素材，完成或清空后启动新轮才采用素材草稿。提示词、尺寸、采样等生成设置仍可实时调整，下一次生成采用新设置，已生成结果继续保留。原生种子固定/递增/递减/随机变化方式按当前提交时规则运行。
本段抽卡使用点击时的最新编辑内容重抽指定段，新结果直接作为该段当前选用；旧版本保留为历史，不失效后续段。新增编辑片段不会增加原有段数。
本轮完成后再点开始才会清空进度重开并采用素材草稿；运行中修改生成设置，下一段即用新设置。原始素材需保留在磁盘；外部改写/移走文件会提示停止，避免悄悄换用新内容。无需新增节点或切换编辑模式。

## v0.4.38 抽卡续跑

本段抽卡的新结果仍自动成为当前选用；修正抽卡临时会话路径被选卡续跑误认为其它轮的问题。合并按预览区仍保留的各段最后结果执行：例如删除#20-3后采用#20-2，再删除则依次回退到#20-1和原始#20，文件和其它历史进度不删除。

## v0.4.36 修复

另存覆盖仅替换选中的目标文件，不连带改写其它硬链接结果；去重复用前重新校验内容，保留用户已修改文件及新生成结果各自的内容。停止只取消本节点绑定任务，不影响其它工作流。独立分段循环逐段更新段索引，同画布使用最新设置，切页仍继续自己的提交副本。

新增素材按轮隔离：当前轮继续使用自己的视频、音频和图片参考，素材编辑留给下一轮，生成设置实时生效。

A/B 整体合并使用完整的逐段最新视频索引，缩略图显示上限不再截断合并清单，保存重载后仍保留；只保存B或仅连接B时正确归入B。正向提示词存在行首#时，首#前说明不计作分段；无#仍按单段处理，独立前后缀保持。打包元数据使用标准无BOM UTF-8。
