# AD-Segmented-Loop 0.4.38

素材时间线、独立分段、逐段预览与选择，以及原文件批处理工具。

## 安装
1. 解压后把 `AD-Segmented-Loop` 文件夹放进 `ComfyUI/custom_nodes`。
2. 用运行 ComfyUI 的 Python 安装依赖：
   `python -m pip install -r custom_nodes/AD-Segmented-Loop/requirements.txt`
3. 重启 ComfyUI 并重新打开页面。节点位于 **AD-Segmented-Loop** 分类。
   环境要求：本版在 ComfyUI 0.43.0 实测通过，建议使用该版本；更早版本尚未完成兼容验证，暂不声明最低支持版本。

## 轨道与切分
轨道小眼睛：关闭后片段变暗，不参与时间线预览、试听及分段输出；再次开启恢复，分段清单排除隐藏轨道，编辑布局保留。编辑、检测、应用切分、应用分段与运行此段只作用于所选可见音视频片段（Ctrl 可多选），未选择时提示先选择。

参考图口按图片加载顺序固定编号；禁止输出保留原编号但输出为空，指定第N段的图片在第N段从自己的参考图口输出。

长时间运行优化：静态视频缩略图与延迟加载；未变化进度采用条件响应并跳过重复写盘；任务边界轻量回收插件解码缓存。保留抽卡历史、源素材、结果与模型，不增加手动清理或卸载模型按钮。

预览分类区的视频卡片使用后端首帧静态缩略图，并按卡片增量更新：结果很多时不再为每张卡片创建视频解码器、不再整表重建，长时间分段循环的预览刷新更轻。存储占用统计降为 60 秒兜底轮询，切回页面或点击占用栏仍立即刷新。

分段循环切到其它工作流标签或界面后仍继续运行：同一画布内每段按当前生成设置运行，本轮素材与下一轮素材编辑隔离；切到别的工作流时使用启动时提交副本继续，不再依赖当前激活画布；旧图界面刷新失败不会中断生成。
生成即通过：正常生成、本段抽卡、改参数后的新生成都自动作为已通过/当前选用，不再需要「同意批准」；点「开始」生成当前段后自动前进，可一段一段生成，点「分段循环」连续生成。预览区拆为「分段生成A」「分段生成B」「合并生成」：A/B 分别显示媒体A/媒体B输入端口逐段内容，合并生成显示点击合并后的结果。「合并片段」点击后弹出「A合并」「B合并」两个选项，点哪个执行哪个；Ctrl 点选时只合并选中片段，不点选则合并该端全部段的最新结果，结果带 A/B 来源标签；A、B 混选会提示请分别合并。分段循环支持报错修复后从报错段继续；选中本轮任意分段预览，再点分段循环，即从该段下一段继续，不要求先清空。重启后或清空重置后同样可用，前段按各自最后结果恢复，后段重跑并保留旧版本；继续使用本轮素材，不串入下一轮草稿。选择本轮末段只显示完成，不重新排队。单击卡片只预览与选择，不自动运行。任务结束时自动回收过期参考帧临时物与已完成抽卡试运行的进度/轮次快照；清理缓存也会回收被新一轮取代的旧轮快照和过期临时文件，不删除素材、结果、成片或当前轮。整轮设置无法准备（例如素材被移动或改写）时，排队会进入已注册的「本轮排队保护」节点并显示真实原因，不再只报“节点不存在”。

全屏预览无边框、黑底等比放大，按钮可再次点击退出；图片/视频的普通与全屏A/B对比均居中完整显示。

选中片段后播放从所选起点开始，多选取最早起点；同一选择停止后继续当前白线。信息栏显示所选第N段，移除源范围与本段范围文案，内部裁剪/计帧数据保留。

工作流切换恢复使用最新编辑器存档，按节点所属图恢复动态参考口与连线，避免同ID工作流或迟到回调相互影响。

## 本轮执行与编辑

素材按轮隔离：本轮使用启动时的素材清单、取段范围与参考素材绑定。运行中替换或编辑的新素材属于下一轮，不影响当前轮；停止续接仍使用本轮素材，完成或清空后启动新轮才采用素材草稿。提示词、尺寸、采样等生成设置仍可实时调整，下一次生成采用新设置，已生成结果继续保留。原生种子固定/递增/递减/随机变化方式按当前提交时规则运行。
本段抽卡使用点击时的最新编辑内容重抽指定段，新结果直接作为该段当前选用；旧版本保留为历史，不失效后续段。新增编辑片段不会增加原有段数。
本轮完成后再点开始才会清空进度重开并采用素材草稿；运行中修改生成设置，下一段即用新设置。原始素材需保留在磁盘；外部改写/移走文件会提示停止，避免悄悄换用新内容。无需新增节点或切换编辑模式。

## v0.4.38 抽卡续跑

本段抽卡的新结果仍自动成为当前选用；修正抽卡临时会话路径被选卡续跑误认为其它轮的问题。合并按预览区仍保留的各段最后结果执行：例如删除#20-3后采用#20-2，再删除则依次回退到#20-1和原始#20，文件和其它历史进度不删除。

## v0.4.36 修复

另存覆盖仅替换选中的目标文件，不连带改写其它硬链接结果；去重复用前重新校验内容，保留用户已修改文件及新生成结果各自的内容。停止只取消本节点绑定任务，不影响其它工作流。独立分段循环逐段更新段索引，同画布使用最新设置，切页仍继续自己的提交副本。

新增素材按轮隔离：当前轮继续使用自己的视频、音频和图片参考，素材编辑留给下一轮，生成设置实时生效。

A/B 整体合并使用完整的逐段最新视频索引，缩略图显示上限不再截断合并清单，保存重载后仍保留；只保存B或仅连接B时正确归入B。正向提示词存在行首#时，首#前说明不计作分段；无#仍按单段处理，独立前后缀保持。打包元数据使用标准无BOM UTF-8。

## 数据目录
- 导入素材：`ComfyUI/input/AD-Segmented-Loop-input/{图片,音频,视频}`
- 保存路径留空：按媒体类型保存到 `ComfyUI/output/AD-Segmented-Loop-output/{图片,音频,视频}`（首次保存时创建）；填写路径后以填写内容为准。
- 生成目录入口：`ComfyUI/output/AD-Segmented-Loop-output`（已有生成归档保留）
- 插件运行数据：`ComfyUI/output/AD-Segmented-Loop-data`
